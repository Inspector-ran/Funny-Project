# 小诗历 1.1.0 · 安卓版

小诗历是独立的离线阅读应用，和东南消息站分开安装。打开安卓 APK 安装后，手机桌面会出现「小诗历」。需要 Android 8.0 或更高版本。

- 「今日」每天按北京时间展示一首完整的唐诗或宋词。同一天重新打开，仍能读到同一首。
- 已装旧版时可直接覆盖安装。首次打开新版当天的作品会留作新一轮的第一首；之前的日期仍按 1.0.0 的规则回看。
- 每轮按比例穿插唐诗与宋词，633 篇各排一次后再循环。首页的小字表示日期在本轮的位置，不是读书打卡统计；没打开的日子也能从「诗历」补读。
- 以后增加诗词时，本机已经开始的一轮不会重排，新作品从下一轮加入。1.1.0 的诗库仍是原有的 633 篇。
- 「诗历」可以从最近的日期中挑选，也可以在日期选择器里回看更早的作品。
- 在诗文页点收藏，之后可从「收藏」重读，收藏只存在这部手机。清除应用数据或卸载会清除收藏。
- 诗词、日历和收藏不需要联网或注册。首版未包含定时提醒、桌面小组件或跨设备同步。

作品来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的唐诗和宋词选集，详见 [诗库来源](诗库来源.md)。授权原文随 APK 和源码附在 `assets/public/poems-license.txt`。

源码使用 Android 原生外壳读取包内页面，没有 Web 服务或互联网权限。用 JDK 17、Android API 35 的 `android.jar` 和 Android Build Tools 执行 `build.ps1`。构建脚本检查包名、签名、资源路径和内容。签名资料需要在源码目录外自行保存，后续覆盖安装应继续使用相同包名和签名。

`assets/public/schedule.js` 内置 1.0.0 的固定 ID 名单，并在本机保存已开始的轮次。扩充诗库时保留所有旧 ID 和正文，追加新记录；删除或改变既有 ID 会丢失相应旧日历文本及收藏。卸载或清除应用数据会清除本机当前轮次的起点和收藏。
