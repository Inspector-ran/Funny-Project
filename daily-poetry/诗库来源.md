# 小诗历 · 诗库来源

首版离线诗库收录 633 篇：唐诗 346 篇、宋词 287 篇。25 篇配有简短的自编阅读提示。正文是古典作品，不含转录网站的现代译文或赏析。

底本是 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的 JSON 数据。固定到提交 `d651e494e0ecb49555f9f473aa7c97ed0e4b53b7`：

- [全唐诗/唐诗三百首.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/全唐诗/唐诗三百首.json)：原文件 366 条。
- [宋词/宋词三百首.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/宋词/宋词三百首.json)：原文件 280 条。
- 从同一提交的 [ci.song.1000.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/宋词/ci.song.1000.json)、[ci.song.3000.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/宋词/ci.song.3000.json)、[ci.song.6000.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/宋词/ci.song.6000.json)、[ci.song.11000.json](https://github.com/chinese-poetry/chinese-poetry/blob/d651e494e0ecb49555f9f473aa7c97ed0e4b53b7/宋词/ci.song.11000.json) 补入 7 阕常读作品。

整理时按正文去掉重复条目，合并明显的异题重收，去掉少量不适合本诗库分类的记录。繁体转为简体并处理常见异体字；部分唐诗显示较通行的篇名，宋词用词牌加题名或首句区分重名。保留底本断句和大部分文字异文。例如《静夜思》采用“床前看月光、举头望山月”的版本，《如梦令·常记溪亭日暮》末句为“惊起一滩鸥鹭”；与部分现代课本使用的版本不同。诗词底本本身不是校勘定本，少量异体字也可能保留。

对发现的明确问题另作少量修正：按[《回乡偶书二首》](https://zh.wikisource.org/wiki/回鄉偶書二首)恢复《回乡偶书（其一）》贺知章的署名；按[李商隐《无题二首》](https://zh.wikisource.org/wiki/無題二首_(鳳尾香羅薄幾重))补齐“凤尾香罗薄几重”一首的末联；按《宋词三百首》目录与相关传本补正韩疁、张镃、赵令畤的姓名。每条诗词保留对应的上游数据链接，方便校对。
