# Funny Project

收录两个独立的安卓小应用。它们分别安装，数据各自保存在手机上。

| 项目 | 版本 | 用途 |
| --- | --- | --- |
| [东南消息站](seu-message-station/README.md) | 1.0.5 | 汇总东南大学教务处及公开公众号通知，支持搜索、收藏、多选整理、置顶、回收站和待办。 |
| [小诗历](daily-poetry/README.md) | 1.1.0 | 离线日历每天安排一首唐诗或宋词，支持往日补读和本机收藏。633 篇排完再循环。 |
| [卡塞尔见习录](cassell-field-notes/README.md) | 插画版 | 卡塞尔学院同人网页文字冒险。四项任务、39 章、17 个结局，手机点开即玩。 |

两个目录都包含源码、构建脚本和涉及的第三方许可。东南消息站首次打开时通过联网刷新获取通知，仓库不复制历史通知正文。小诗历的诗库和 [来源说明](daily-poetry/诗库来源.md) 随源码提供。

安卓构建使用 JDK 17、Android SDK Platform 35 和 Build Tools。用各项目的 `build.ps1` 并传入所需路径。签名材料应保存在仓库外；首次自行构建的安装包要使用自己的签名，覆盖已安装的版本时需沿用原签名。

小诗历「每日一句」是后续想法；会与「每日一首」分开，计划收录有明确出处的古今中外书摘。
