# 毛毛雨小镇居民观察室

这是「小然和糯米」的独立原型，复用小镇地图和小人画法。原型使用自己的 SQLite 存档。

## 运行

在本目录用 Node.js 24 或更新版本运行 `node server.mjs`，再打开 [居民观察室](http://127.0.0.1:4178/)。关掉网页后，运行中的服务仍会每 12 秒推进一次。停止服务后模拟暂停，重新启动会从存档继续。

缺少模型配置时，观察室显示「规则演示」，居民会自主行动并展示示范对白。要测试自由对话，请在运行服务的环境设置 `OPENAI_API_KEY`。可以用 `RAIN_TOWN_MODEL` 指定支持 Responses API 结构化输出的模型，默认是 `gpt-5-mini`。模型密钥只由服务端读取。成功生成的对白标为「模型生成」。服务每隔至少 45 秒才会尝试一次模型调用，并且只在符合条件的相遇或决策轮次调用。

如需独立存档，可在启动前把 `RAIN_TOWN_DATABASE` 设为另一份 SQLite 文件路径。运行 `node --test prototype.test.mjs` 检查自主行动、隔天回忆、行动校验、无人访问时推进和重启恢复。模型适配器测试使用替代响应，真实生成效果需要连接模型观察。

## 大脑与引擎

| 代码 | 职责 |
| --- | --- |
| `town-data.mjs` | 人格起点、愿望、地图与相邻地点 |
| `engine.mjs` | 状态、决策候选、行动执行、关系、记忆、游戏时间 |
| `openai-brain.mjs` | 把各自的情境和相关记忆交给模型，由模型提议行动和对白 |
| `store.mjs` | 保存SQLite状态，用版本号防止覆盖更新 |
| `server.mjs` | 启动定时推进，自身运行时无需玩家在线 |

例如，小然想去观景台时，引擎先查当前地点的相邻路径。到达后才提供描星图的选项。碰到糯米时，两人的精力和上次交谈时间都符合条件才允许聊天。引擎记录双方各自记住的经历，并根据这次互动更新熟悉度。模型收到行动候选和记忆，返回的结果还要经过引擎校验。

建议和特殊安排属于后续版本。上线共享版前还需要验证真实模型的开放式对话、核实居民是否根据过往经历改变回应，并给生产调度设定预算。
