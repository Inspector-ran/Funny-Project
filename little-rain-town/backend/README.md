# 毛毛雨小镇共享存档

共享版沿用 GitHub Pages 的网页。Supabase 保存居民、见面记录和小镇时间。任何人都能浏览小镇，参与者打开同一网址就可以捏小人。

## 配置

1. 在 Supabase 项目的 SQL Editor 运行 [setup.sql](setup.sql)。
2. 在项目的 Connect 面板复制 Project URL 和 Publishable key，分别填入 [shared-config.js](../shared-config.js) 的 `projectUrl` 和 `publishableKey`。这两个值供网页使用，数据库密码和 secret key 保存在仓库外。
3. 将游戏目录中的六个网页文件发布到 GitHub Pages 分支的根目录。发布后，用两个独立浏览器会话检查居民列表和小镇动态能否同步。

## 小人的归属

网页给访客的浏览器生成一个随机识别码。服务器为这个识别码保留一个小人名额。正常刷新页面或打开新标签页时，可以继续编辑原来的小人。不同浏览器有各自的识别码，清除网页存储也会重置识别码。

居民昵称、外观、口头禅和互动记录在游戏里公开显示。识别码由原来的浏览器保存，数据库只存哈希值。

共享模式从三名默认居民开始。用原来的浏览器打开捏人面板，可以从自己的旧存档挑一个小人，确认后带进共享小镇。
