# 东南消息站 Android

当前版本 1.0.5（versionCode 6）：可跨页选中全部筛选结果或已读消息，支持批量已读、置顶、取消置顶、移入回收站和恢复。升级沿用原包名、签名和 SQLite 数据结构。

- 当前筛选结果一键已读，包含未加载页；确认时锁定消息 ID，之后新到消息仍未读。最近一次批量操作可在 2 分钟内撤销，撤销记录可跨重启。
- 列表快捷已读／未读和收藏，详情可标回未读；未读角标、筛选计数、来源未读数及时更新。所有整理操作离线可用。
- 来源卡片可直接进入对应消息；快捷只看未读、清除筛选和已读筛选。
- 待办按全部／待完成／已逾期／已完成查看，“明天再办”保留原时分，未设时分则使用 18:00；同一通知已有未完成待办时直接编辑，避免重复创建。

批量接口为 `GET /api/messages/selection`（返回筛选范围的消息 ID）、`POST /api/messages/batch`（action、filters 或 ids，preview=true 返回确认范围）与 `POST /api/messages/undo`（token）。原生 `flags` 在 SQLite 事务中更新已读、收藏、置顶时间及删除时间，允许有条件地撤销。同步更新消息内容时保留数据库内的这四个本地字段。回收站消息保留原记录和待办关联，不计入普通列表和未读统计。

手动刷新、打开／返回应用检查和系统后台任务统一使用原生 `SyncCore`、`NativeHttp`，更新不依赖隐藏 WebView。每次检查保存新增数、修订数、完成时间及逐来源错误；一个渠道失败不阻塞另一个渠道。

保留 1.0.1 的首页加载修复：`tools/NormalizeApk.java` 在签名前规范 ZIP 路径，`verify-apk.ps1` 验证所有 8 个页面资源与源码内容一致。升级沿用原包名和原签名，覆盖安装保留手机数据。

独立的安卓应用。离线网页界面搭配 Android SQLite、Android Keystore、原生网络请求与 JobScheduler；不运行 Node.js 服务，也不连接个人电脑。

`src/` 为原生宿主；`assets/public/` 为界面与业务；`res/` 为应用主题和图标。仓库里的 `seed.json` 为空模板；首次打开，请联网并点「刷新消息」获取最新通知。

构建需要 JDK 17、Android API 35 的 android.jar、Build Tools 36.0.0，以及 ZXing Core 3.5.3、jsoup 1.21.2（均在 `libs/`）。使用 `build.ps1` 的显式参数指定工具位置、签名文件与密码文件。私有签名材料未包含在源码中；后续覆盖安装必须沿用原签名。

接口功能包括统一收件箱、来源管理、手动收集、收藏、搜索、待办日历、备份恢复、可选模型摘要与微信读书补充连接。

主要内容接口为教务处官网与 SEU Wiki 免费公开接口。完整性、更新频率及每个来源的可用状态均以实际返回为准。

`tests/SyncCoreTest.java` 使用正式同步代码验证去重、保留收藏／已读／正文、网络失败和来源隔离。JVM 上需额外提供测试用 org.json 20250517 jar：与 jsoup、SyncCore、NativeHttp 一起编译；无参数运行固定测试，传入 `live <seed.json路径> all` 执行真实 HTTPS 检查。不要将测试用 org.json 打包进 Android（系统自带）。
